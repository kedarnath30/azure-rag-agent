# Data

`docs/` holds 15 short HR and benefits policies for **Brightwater Analytics**, a fictional company.
They were written for this project, describe no real employer, and are released under the
same MIT license as the code.

`eval/golden.jsonl` holds the golden Q&A set used by `ragagent eval`. Each line has the question,
the document that should be retrieved (`expected_doc`), and keywords the answer should contain.
